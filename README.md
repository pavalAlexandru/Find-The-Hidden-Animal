# 🐾 Find the Hidden Animal 

## 📖 About This Project
This project was developed as an intensive exam preparation for the **Systems for Design and Implementation** course. 

The goal of the application is to demonstrate a fully functional client-server architecture using REST APIs and real-time WebSockets. Players must guess the location of a hidden animal on a 3x4 grid within 3 attempts, with the server providing directional hints (North, South, East, West). The application also features a live, real-time leaderboard ranking players by how fast they win, and a configuration form to add new animals to the database.

## 🛠️ Comprehensive Technology Stack

### Frontend Development Environment
* **React:** The core JavaScript library used for building the component-based user interface.
* **Vite:** The lightning-fast build tool and development server (executed via **Terminal** with `npm run dev`).
* **Axios:** Promise-based HTTP client used to handle standard REST communication (starting sessions, making guesses, posting configurations).
* **@microsoft/signalr (NPM Package):** The client-side library used to establish a WebSocket connection and listen for real-time leaderboard updates.
* **CSS3:** Standard cascading stylesheets for the 3x4 grid layout, button states, and leaderboard formatting.

### Backend Development Environment
* **.NET 10 / C#:** The core runtime and language powering the backend server.
* **ASP.NET Core (Controllers):** Handles the standard REST API endpoints (`/api/game/start`, `/api/game/guess`, `/api/game/config`).
* **Entity Framework Core (EF Core):** The Object-Relational Mapper (ORM) used to translate C# LINQ queries into SQL.
* **SQLite:** The lightweight, file-based relational database (`JocAnimaleMPP.db`) used to store Players, Game Sessions, Guesses, and Game Configurations.
* **SignalR:** The ASP.NET Core library used to push live leaderboard updates to all connected React clients the moment a game is won.
* **Swagger / OpenAPI:** Autogenerated documentation and testing UI for the REST endpoints (accessible in the browser during development).

### Developer Tools (IDE & Terminal)
* **IDE (JetBrains Rider and NeoVim):** Used for code editing, syntax highlighting, and attaching the debugger to catch runtime exceptions.
* **dotnet CLI (Terminal):** Used for restoring NuGet packages, running the backend (`dotnet run`), and managing EF Core migrations if necessary.
* **Node Package Manager (npm):** Used in the terminal for managing frontend dependencies.
